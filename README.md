# 🔱 Baba App - Bol Bam

**Tagline: Ghar Se Ghar Tak - Har Kadam Surakshit**  
**Mission: Ek bhi Bam ko dikkat na ho**

## ✨ Features
- 📿 **District/State Wise Panda List** with Home Address & Mobile
- 🏠 **Dharamshala + Hotel** list with Rate
- 🚕 **Car, Auto, E-Rickshaw** booking number
- 👨‍⚕️👮🚒 **Dr, Police, Fire Shivir** location
- 🏪 **Shop List + Anti-Thagi Complaint** 
- 🗺️ **Route + Pass System + Line Status**
- 🔊 **Voice**: Happy Sawan, Om Namah Shivaya, Har Har Mahadev
- 🎵 **Baba Bhajan & Video Darshan**
- ❗ **Missing Person Report** - Direct Govt Info
- 🔒 **100% Free, No Login, No Aadhar**

## 🛠️ Kaise Chalaye
1.  Repo ko download karein
2.  `index.html` ko browser me kholein
3.  `assets/audio` me bhajan.mp3 daalein

## ⚖️ DISCLAIMER
Ye ek Public Service App hai. Govt of India/Jharkhand se sambadhit nahi hai. 
Hum koi data collect nahi karte. Emergency me 112 call karein. 
Shop/Panda ki jankari ko verify kar lein.
